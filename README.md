# Tasira releases

Installers and automatic updates for Tasira (تسعيرة), corrugated carton pricing software by
Vetta Digital Systems.

This repository holds release files only, no source code. Each release has the Windows installer,
its signature, and `latest.json`, which Tasira reads to find new versions. Updates are signed;
Tasira installs only files signed with Vetta's key.

Releases are published automatically from the private source repository. Don't upload files here
by hand.
